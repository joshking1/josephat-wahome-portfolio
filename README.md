## Featured work

### 1. Financial calculations in Excel
I use Excel extensively to calculate revenue and organize financial figures for review. The worksheet structure makes the calculation understandable and supports business reporting.

### 2. Request records in Excel and Google Sheets
I organize client requests in a consistent tabular structure. The team transfers those records into the RMS, which connects with Excel, while Google Sheets provides additional storage. Find, including Command + F, helps the team retrieve a client's original request without writing a database query.

### 3. Reader-focused documents in Word and Python
I combine Word, Python and hands-on design to create documents for clients, Operations, task executors, beneficiaries and institutions. I work on content, visual hierarchy, layout and reusable formatting components. The authoritative execution record and the reader's needs guide each document.

### 4. Document preservation and recovery
I use Cloudflare R2 and a private cPanel archive to preserve documents and restore access when links expire or break. The recovery workflow avoids recreating documents and helps clients and the team regain access to their records.

## My engineering approach

- Keep one authoritative execution record as the source for operational communication.
- Let the reasoning determine which information each reader needs.
- Check arithmetic, disclosure permissions and release integrity.
- Preserve human review, approval and sending authority.
- Verify releases with version identifiers and SHA-256 integrity checks.

## Website implementation

The portfolio is a responsive, buildless HTML/CSS/JavaScript site. It uses semantic sections, keyboard-accessible reader tabs, visible focus states and a mobile layout. It has no third-party scripts, tracking or required account login.

To view locally, serve this directory with any static server, for example:

```sh
python3 -m http.server 8000
```

Open `http://localhost:8000`. The published site is served by GitHub Pages from the repository root.
